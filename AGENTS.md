# Scoutech

Zip line (tyrolienne) simulator: computes cable/rope statics, ground clearance, rider
dynamics and equipment sizing for spans >50 m.

Package manager is **bun**. TanStack Start in SPA mode (file-based router, static build on
GitHub Pages) · React 19 · Tailwind v4 · shadcn/ui on Base UI · Vitest. Setup and scripts:
[README.md](README.md). Workflow — issues, commits, checks, tests, releases:
[CONTRIBUTING.md](CONTRIBUTING.md).

## Before declaring work done

Run every command in [CONTRIBUTING.md § Checks](CONTRIBUTING.md#checks) — CI gates the PR on them —
plus the full `bun run test`. Commits follow [§ Commit messages](CONTRIBUTING.md#commit-messages):
release-please builds the version and changelog from them.

## Never edit

- `src/routeTree.gen.ts` — generated by `@tanstack/router-plugin`.
- `src/components/ui/**` — add via `bunx shadcn@latest add <component>`, then customise.
- `CHANGELOG.md`, `package.json` `version`, `.release-please-manifest.json` — owned by release-please.

## Formatting

Format the files you touched — `bunx oxfmt --write <path>` — never the repo-wide `bun run format`;
`bun run format:check` (repo-wide, read-only) is what CI runs.
Markdown and `src/routeTree.gen.ts` are in `.oxfmtrc.json`'s `ignorePatterns`: specs, tickets and
reference reports are the contract, and the route tree is generated — neither is a formatter's to
rewrite.
