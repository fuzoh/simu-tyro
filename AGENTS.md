# Scoutech

Zip line (tyrolienne) simulator: compute cable/rope statics, ground clearance, rider
dynamics and equipment sizing for spans >50 m.

## Stack

TanStack Start (SSR, file-based router) · React 19 · TypeScript · Tailwind v4 ·
shadcn/ui on Base UI primitives · Vite 8 · Vitest.

## Commands

Package manager is **bun** (`bun.lock`).

```
bun run dev        # vite dev, port 3000
bun run test       # vitest run
bun run lint-type-aware # Oxlint
bun run typecheck  # tsc --noEmit
bun run format     # oxfmt
```

Run `typecheck` + `lint` before declaring work done.

## Hard constraints

- Never edit `src/routeTree.gen.ts` — generated by `@tanstack/router-plugin`.
- Never hand-write files in `src/components/ui/` — add via
  `bunx shadcn@latest add <component>`, then customise.
- No `tailwind.config` file: Tailwind v4 theme lives in CSS vars in `src/styles.css`.
  shadcn config: `style: base-lyra`, `baseColor: mist`, icons from `lucide-react`.

## Conventions

- Prettier owns formatting (no semicolons, double quotes, 80 cols). Don't argue with it.
- Import alias `@/*` → `src/*`.
- `verbatimModuleSyntax` is on — type-only imports need `import type`.
- Routes are files under `src/routes/`; use `createFileRoute`.
- `strict`, `noUnusedLocals`, `noUnusedParameters` are on.

## Domain references

`docs/references/*.md` — long French engineering reports on zip line physics
(catenary/parabolic sag, cable vs rope, MBR and safety factors, anchor sizing,
termination efficiency). Read the relevant one before touching simulation math or
safety-factor logic; do not invent formulas or coefficients.
